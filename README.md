# Español · 3 класс — интерактивный курс

Статический трёхъязычный курс испанского языка для 3 класса (Español · русский · English):
страница-содержание и 19 интерактивных уроков.

## Что внутри

- `index.html` — содержание курса (Unidades 1–9).
- `unidad-*.html` — 19 уроков.
- `robots.txt` — правила для поисковых роботов.

## Возможности

- 🔊 Озвучка испанских слов и фраз — встроенный синтез речи (TTS, голос `es-ES`).
- 🎮 Интерактивные задания: викторины, «найди пару» (memory), сортировки, сборка слов.
- 👁 Переключатель переводов — кнопка внизу справа прячет русский и английский.
- 🔗 Ссылки на внешние игры по темам (Rockalingua, Digital Dialects, Quizlet, портал adu.by).

## Технологии

Чистый HTML с инлайновыми CSS и JS — без сборки, фреймворков и зависимостей.
Достаточно открыть `index.html` в браузере.

## Публикация (GitHub Pages)

Сайт раздаётся напрямую из ветки `main` (корень репозитория).
